Abstract Layer privacy policy

Last updated: 25 October 2026

"Abstract Layer" is a private command-line tool that Yasser Yahia uses to manage the Abstract Layer YouTube channel: uploading videos and editing titles, descriptions, thumbnails, captions and playlists. It is not offered to the public.

What data it accesses

With the channel owner's consent, the tool uses the YouTube Data API to read and change that one channel's videos, playlists and metadata. It requests no other Google data.

How data is stored

The OAuth token is stored only on the owner's own computer. No data is sent to any server other than Google's, and none is sold, shared or used for advertising.

Revoking access

Access can be revoked at any time at myaccount.google.com/permissions. The tool's use of YouTube API Services is subject to the YouTube Terms of Service and the Google Privacy Policy.
